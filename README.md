# かんじれんしゅう（Web版 v0.2.1）

漢字学習アプリ仕様書 v0.1 にもとづく初期版です。Safari で動く Web アプリ（PWA）で、iPad のホーム画面に追加するとアプリのように全画面で使えます。

## 入っているもの

| ファイル | 内容 |
|---|---|
| index.html | アプリ本体（1ファイル） |
| manifest.webmanifest / sw.js | ホーム画面追加とオフライン起動のための設定 |
| icon-*.png | アイコン |
| sample.csv | 読み込み確認用のCSV（UTF-8、見出しあり） |

## iPad で使うまで

PWA は https のサイトに置く必要があります。無料で使える例として GitHub Pages の手順を示します。

1. GitHub で新しいリポジトリ（例：kanji-renshu）を作り、このフォルダの中身をすべてアップロードする。
2. リポジトリの Settings → Pages で、Branch を main / root にして保存する。
3. 数分後に表示される URL（https://ユーザー名.github.io/kanji-renshu/）を iPad の Safari で開く。
4. 共有ボタン →「ホーム画面に追加」。以後はホーム画面のアイコンから起動する。

一度開けば、アプリ本体とフォントが端末に保存され、通信がなくても学習できます。Netlify Drop などに フォルダをドラッグして置く方法でも動きます。

## データの保存

問題集・途中の学習・成績・復習の状態は、その iPad のブラウザ内（localStorage）に保存されます。

- ホーム画面に追加したアプリと、Safari で開いたページは別々の保存場所になります。どちらか一方に決めて使ってください。
- アプリの削除や「履歴とWebサイトデータを消去」で消えます。バックアップは仕様書どおり将来拡張です。

## 初期版で実装した範囲

- CSV 読み込み：UTF-8（BOM有無）／Shift_JIS(CP932) の自動判定と手動切替、見出し自動判定と切替、引用符内のカンマ・改行・""、欠損行の行番号表示と「除いて取り込む」、構文エラーは取込不可、D列以降の通知、完全重複・同音異字の警告、0問は取込不可、再取込は新しい版として保存
- 4モード＋⑤ごちゃまぜ（各問題に①〜④をランダムに割り当て。復習でも同じくランダム。学習を始めるたびに割り当て直し、「つづきから」では同じ割り当てを保つ。成績と復習は実際に出したモードで記録）、ぜんぶ／ふくしゅう、じゅんばん／ランダム（開始時に1回だけ並べ替えて固定）、画面に書く／紙に書く（①④のみ）、直前の選択を引き継ぐ
- 書き取り欄：ペン・指、けしゴム（線ごと消す）、1つもどす、ぜんぶけす、マス目、回転しても筆跡を保持、座標・時刻・順序を保存
- 答え画面で自己採点（③は読み・意味を別々に）、採点するまで「つぎへ」無効、連打で問題を飛ばさない、最後も答え画面を経由
- 結果：得点（四捨五入）＋正解数、③は読み・意味の正答率、まちがい一覧、「今回のまちがいをふくしゅう」「もういちど ぜんぶ」
- 復習：問題集・問題・モードごとに未克服を管理、正解で解除・誤答履歴は保持、別モードの正解は影響しない
- 途中終了と再開（出題順・位置・書きかけの筆跡・採点の選択を復元）
- おうちの人へ：CSV取込、問題集の削除、指入力・効果音・きき手の設定、これまでの記録

## 更新するとき

GitHub で index.html と sw.js を上書きアップロードすれば、iPad のアプリを開き直したときに新しい版になります。問題集や記録は消えません。
